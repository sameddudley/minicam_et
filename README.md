# Affordable thermal camera imaging system for modeling evapotranspiration
This repo documents the hardware and software required to build and run an affordable thermal temperature sensor and datalogger to estimate evaopotranspiration (ET). 

## Estimating evapotranspiration from thermal data
This sensor measures surface temperature of the field of view (FOV) in a 24x36 grid of pixels. Using this surface temperature data you can retrieve temperature data to be used for multiple modeling approaches including the Two Source Energy Balance Model (TSEB), the Wavelet method, or crop water stress index (CWSI).
